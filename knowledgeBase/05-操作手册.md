# 操作手册(命令速查)

## 流水线命令(工作目录 E:\ai\story2video,解释器 python_embeded\python.exe)

```bash
python pipeline.py new <故事名> [源txt]   # 新建故事并切换(故事库 E:\ai\stories\)
python pipeline.py list                   # 列出所有故事
python pipeline.py script                 # 阶段0-2:方向→梗概→草稿
python pipeline.py rewrite                # 27B 创作级改写
python pipeline.py assets                 # SDXL 定妆图/场景图
python pipeline.py transitions            # 插入过渡空镜
python pipeline.py generate               # 视频生成(引擎由 settings 决定)
python pipeline.py audio                  # edge-tts 情绪配音
python pipeline.py concat                 # 混音拼接成片
python pipeline.py all                    # 全流程(rewrite 受 settings 开关控制)
```

## settings.json 关键项

| 键 | 值/说明 |
|---|---|
| 当前故事 | 故事库中的故事名 |
| 视频引擎 | comfyui(本地)/ jimeng(即梦 API) |
| 即梦.api_key | 火山方舟 API Key |
| 即梦.model | doubao-seedance-2-0-260128(标准)/ -fast-260128(便宜)/ 2-5-260628(长镜30秒) |
| 画面定调.风格 | 二次元3D渲染(当前)/ 国漫水墨 / 真人电影… |
| 视频.宽度/高度/帧数 | 1280/544/121(宽银幕,5秒) |
| 编剧.启用27B润色 | true/false |

## 日常维护

- **清理前先问备份**(付费产物)+ 即梦调用前先问同意
- 换剧本/换引擎后必清:story 目录的 state.json、clips\*.mp4、audio\*.m4a、final_story.mp4
- Ollama 假死:重启 serve,显式带三个环境变量(见 03-复盘与坑 #5)
- 网络假死(curl 全 000 但浏览器通):安全软件拦截,用 PowerShell 或浏览器下载
