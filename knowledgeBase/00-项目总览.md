> 知识库版本:v1.0 | 2026-10-28 | 本文件是一页速览,详细内容见同目录其他文件

## 一句话

输入一篇小说,全自动产出带情绪旁白的动画短片 mp4——一台"AI 制片机":剧本、导演、资产、视频、配音、成片六大环节全自动,视频引擎可插拔(本地 Wan ⇄ 即梦 API)。

## 硬件与模型栈

- RX 9070 XT 16GB / 32GB RAM / Win11(原生 ROCm)
- 视频:Wan 2.2 TI2V-5B(本地)/ Seedance 2.0(即梦 API)
- 图片:SDXL + 可选水墨 LoRA(1024×1536 定妆图)
- 剧本:Lumen 14B(快写)+ qwen3.6 27B(精修)
- 配音:edge-tts(晓晓)+ 情绪标签自动变调

## 关键结论(截至 2026-10-28)

1. **静态图已达主流水平**(SDXL);**视频画质天花板在模型**:本地 5B 与 Seedance 2.0 存在代差(10 题测试集+同镜对比已量化)
2. **即梦 API 的隐藏成本**:内容审核随机拦截(军旅题材 9 连拒)、单条约 2 元(fast 版)
3. **本地引擎的不可替代性**:零成本、零审核、可无限试错——定位为样片/草稿引擎
4. **待决策**:引擎选型(本地 / 纯即梦 / 混合)、新题材(避开军事敏感,候选:都市情感/甜宠/悬疑/温情)
