# 流水线架构

## 全链路图

```
story.txt
  → [阶段0 改编方向] Lumen 14B:3个方向自评选优 → directions.json
  → [阶段1 分镜梗概] Lumen:8~12镜梗概+人物档案 → script_plan.json
  → [阶段2 逐镜草稿] Lumen:链式上下文(最近2镜)+导演规则 → script.json(增量落盘)
  → [阶段2b 27B改写] qwen3.6:创作级改写(对白/情绪/紧迫感,景别锚点锁死)
  → [阶段2c 资产] SDXL:角色定妆图+场景设计图(1024×1536,质量闸门防灰图)
  → [阶段2d 过渡镜头] LLM:关键跳变处插入2-3个环境空镜(2秒,无旁白)
  → [阶段3 视频生成] 双引擎:
       comfyui:Wan2.2 5B,每镜重启服务器,I2V锁角色(assets/char_ref.png)
       jimeng:Seedance API,异步任务+轮询+下载
  → [阶段3a 配音] edge-tts:情绪标签[低沉]/[激昂]→rate/pitch映射,无标签自动推断
  → [阶段3b 拼接] webp→mp4(流式)+ 混音(-shortest)+ concat → final_story.mp4
```

## 双引擎设计(核心抽象)

- settings 的 `视频引擎` 字段:comfyui / jimeng
- 两个引擎的产物同构:`clips/clip_XX.mp4` — 配音/拼接阶段无感知
- GPU 排他:LLM(Ollama)与 ComfyUI 不能同时占卡 → stop_ollama()/start_ollama() 与 stop_comfy()/start_comfy() 成对交接,**整进程停对方**(模型卸载不够,ROCm 残留会挂死新进程)

## 故事库模式

```
E:\ai\stories\<故事名>\
├── story.txt / directions.json / script_plan.json / script.json
├── assets\ 角色定妆图+场景图+char_ref.png(确认的主角图)
├── clips\ 分镜片段 / audio\ 旁白
└── final_story.mp4 成片
```
- 切换故事:`settings.json 当前故事`;新建:`pipeline.py new <名> <源txt>`
- 列表:`pipeline.py list`

## 断点续跑

- state.json:已完成镜头列表(视频阶段)
- script.json:逐镜增量落盘(剧本阶段)
- 所有阶段可安全中断重启,重跑自动跳过已完成项

## 实验模式(引擎对照)

- 素材:人工锁定分镜表(开源成熟剧本+现成提示词)
- exp_run.py jimeng/local:组1纯本地 / 组2纯即梦,每镜3候选,盲测评分
- 组3混合不实跑,用组1废片率+即梦单价推算性价比
