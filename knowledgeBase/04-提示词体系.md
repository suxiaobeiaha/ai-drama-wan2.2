# 提示词体系(画面质量宪法)

> 原始文件:E:\ai\story2video\提示词模板.md(全文含运镜/景别备选表)

## 第一部分:基础定调(settings.json 驱动,全局一次)

- **风格档位**:真人电影 / 韩漫 / 日漫 / 国漫水墨 / **二次元3D渲染(当前默认)** / 3A游戏CG厚涂
- 摄影机:ARRI Alexa 65(默认);镜头:50mm f/2.8;胶片:柯达5219
- **规则:漫剧风格下摄影机/胶片参数自动被风格描述覆盖**(代码已实现)
- 技术标准:24fps、宽银幕、全局限制(无畸变/穿帮/多余空镜)

## 第二部分:分镜公式(每个视频提示词必须遵守)

```
运镜方式 + 景别 + 主体 + 核心动作 + 人物表情 + 限制条件
```
- 运镜:固定机位/缓慢推进/缓慢后拉/横移/摇摄/360环绕/斯坦尼康
- 景别:特写/近景/中景/全景/远景
- 即梦理解力强,电影术语全部生效;本地 Wan 5B 只认简单风格词(复杂术语是噪音)

## 第三部分:导演规则(制片人 2026-10-17 定稿)

1. 开场镜必须是远景定场(大军氛围)再入人物
2. 对话以正反打为主(一人一镜交替);**关键情绪对比时刻例外:双人同框**(如斥候来报:镇定 vs 紧张)
3. 关键情绪转折点用面部特写
4. 相邻镜头景别必须不同;一镜一动作
5. 景别必须锁死梗概设定(27B 改写曾把远景全改特写,被驳回后加锚点)

## 第四部分:旁白规范

- 开头带情绪标签:[低沉]/[激昂]/[悲壮]/[紧张]/[平静]/[惊讶]/[温柔]/[俏皮]
- 20-25 字,口播风格,删连接词,可呼吸停顿
- 含对白/表情动作/紧迫感要素(战争题材)
- edge-tts 映射:低沉 -15%/-20Hz、激昂 +10%/+10Hz、悲凉 -20%/-20Hz

## 适配经验

- 即梦审核雷区:军装/军衔/肩章/军事番号(火箭军)→ 军装改工装、番号改虚构、血腥词软化(blood→crimson glow)
- 两引擎同提示词时,提示词要按"最低公共理解力"(Wan 5B)写,即梦只会更好
