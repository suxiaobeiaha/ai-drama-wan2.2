# 通用提示词模板(电影级分镜规格)

> 本文件是画面质量的"宪法",流水线逐镜写提示词时自动引用。
> 全局可调参数见 settings.json;修改本文件后重跑 script 阶段即可生效。

---

## 第一部分:基础定调参数(全局统一,只写一次)

### 分辨率
8K 超高清电影级画质

### 摄影机
- **默认**:ARRI Alexa 65 大画幅摄影机质感
- 备选:RED V-Raptor 8K、索尼 Venice2、IMAX 70mm 胶片、RED Komodo 6K(短剧性价比首选)

### 镜头
- **默认**:50mm 中焦定焦镜头,f/2.8 浅景深
- 备选:35mm 广角(环境叙事)、185mm 长焦(人物特写)、24mm 超广角(大场景)、变形宽银幕镜头(电影感)

### 胶片/质感
- **默认**:柯达 5219 电影胶片,细腻自然颗粒
- 备选:柯达 Portra 400(人像暖调)、Cinestill 800T(夜景霓虹)、富士 Superia 100(清新日系)、无胶片(纯数码锐利)

### 技术标准
- 24fps 院线标准帧率
- 2.39:1 宽银幕画幅
- 8 秒固定时长(⚠️ 本机流水线适配:Wan 2.2 模型上限 121 帧 ≈ 5 秒,见 settings.json)

### 全局限制
- 全程无超帧、无画面畸变、无多余空镜、无穿帮
- 人物台词与唇型 1:1 精准同步

### 真人专属补充
- 无 AI 失真脸、皮肤保留自然毛孔纹理、无过度磨皮美白、手部动作自然无畸形

### 漫剧专属补充(替换上方【摄影机+胶片】)
- **韩漫**:manhwa webtoon 风格,清晰线条,平涂上色
- **日漫**:吉卜力手绘风、新海诚光影风、赛璐璐复古风
- **国漫**:东方水墨风、3A 游戏 CG 厚涂风

## 第二部分:分镜时序与运镜(逐秒精准控制)

### 标准公式
```
x秒-x秒:运镜方式 + 景别 + 主体 + 核心动作 + 限制条件
```

### 常用运镜备选
| 运镜 | 用途 |
|---|---|
| 固定机位(带极轻微自然呼吸感) | 情绪聚焦、对话场景,容错率最高 |
| 缓慢匀速向前推进 | 强化情绪、引导视线 |
| 缓慢匀速向后拉开 | 展现环境、制造反差 |
| 水平左/右横移 | 展示空间、跟随人物移动 |
| 垂直上/下摇摄 | 揭示上下空间、突出气势 |
| 360° 缓慢环绕 | 全方位展示主体、营造氛围感 |
| 斯坦尼康跟拍 | 沉浸式跟随、动作场景 |

### 常用景别备选
| 景别 | 用途 |
|---|---|
| 特写(面部/手部) | 极致情绪 |
| 近景(胸部以上) | 对话、表情 |
| 中景(腰部以上) | 人物动作+环境 |
| 全景(全身+环境) | 场景交代、动作场面 |
| 远景(大环境) | 氛围渲染、转场 |

### 分镜示例
- 0-2秒:固定机位,中景,男主站在雨中,低头看着手中的信封,雨水打湿头发,镜头焦点锁定信封
- 2-5秒:缓慢向前推进,从全景推至特写,男主缓缓抬起头,眼神从迷茫转为坚定,背景逐渐虚化

## 第三部分:导演规则(叙事镜头结构)

> 制片人 2026-10-17 定稿。所有分镜必须遵守。

1. **开场定场镜**:第 1 镜必须是远景,展现大军决战氛围(旌旗蔽日/铁骑列阵/战云压城),再过渡到主角对话
2. **对话正反打**:两人对话的剧情以交替镜头为主——一个镜头只拍一个人,镜头在两人之间切换。**例外**:关键情绪对比时刻可用双人同框(如斥候来报:主角的镇定与同伴的紧张同框,形成反差张力)
3. **关键情绪特写**:剧情关键转折时刻,安排面部特写凸显人物神色(目光/眉宇/指节等细节)
4. **景别交替**:近景(情绪)与远景(环境)穿插,相邻镜头景别必须不同,避免连续重复
5. **一镜一动作**:每个镜头只保留一个核心动作或信息点,拒绝镜头重复与剧情冗余
