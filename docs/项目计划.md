## 重大决策记录(2026-10-17)

- **画质路线(Seedance 2.0 对比)**:本地 16GB 卡达不到商业视频模型级别,差距是模型代差。三条路径(本地升级 HunyuanVideo-1.5 / 混合方案接即梦 API / 云 GPU)待制片人看过本地成片后决策,详见 优化线路与决策树.md D11

## 重大决策记录(2026-10-24)

- **引擎对照实验(三组改两组)**:制片人定调——先跑组1(纯本地)与组2(纯即梦)对照,**组3(混合)的性价比用组1+组2数据推算**(预期成本=本地废片率×即梦单价,预期质量=组2),推算有利才真跑组3
- **成片时长目标定稿**:≥1 分钟(12-14 镜×5秒,或即梦 30 秒长镜路线)
- **实验方法论**:控制变量——人工锁定分镜表(成熟剧本片段)+ 每组每镜 3 条候选 + 盲测评分;剪辑人工处理,自动拼接等产出稳定后再启用
- **待制片人定**:实验剧本选材、每组每镜条数(3 条/2 条)
