# 阶段总结:小说 → AI 动画短片流水线

> 总结时间:2026-10-21 | 阶段:M0–M3 完成,待制片人决策画质路线

---

## 一、项目是什么

输入一篇小说 → 全自动产出带情绪旁白的动画短片 mp4。全流程:剧本 → 导演 → 资产 → 视频 → 配音 → 成片。

**核心架构(双引擎)**:

```
小说 → [Lumen 14B] 三方向自评 → 分镜梗概 → 逐镜草稿
     → [qwen3.6 27B] 创作级改写(对白/情绪/紧迫感,导演规则5条)
     → [过渡镜头] 呼吸感空镜插入
     → [SDXL+LoRA] 角色定妆图/场景设计图(1024×1536,制片人审查)
     → [视频引擎] comfyui(本地Wan2.2 5B,I2V角色锁定) ⇄ jimeng(即梦API,待Key)
     → [edge-tts] 情绪标签旁白(晓晓音色,低沉/激昂/悲壮自动变调)
     → [ffmpeg] 混音拼接 → 成片 mp4
```
