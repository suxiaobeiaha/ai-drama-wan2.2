# 需求文档:小说 → AI 动画短片流水线

> 版本 v1.0 | 2026-10-16 | 本文档是项目的需求基线,需求变更请同步更新并告知 Claude

---

## 1. 项目概述

把小说文本自动转化为带旁白的动画短片:本地 LLM 写剧本 → 本地视频模型逐镜生成 → TTS 配音 → 自动合成 mp4。全程在本机(RX 9070 XT 16GB / 32GB RAM / Windows 11)离线完成。

## 2. 项目目标

- **核心目标**:输入一篇小说(章节),产出可在手机上直接观看分享的成片
- **成片时长(2026-10-24 定稿)**:成片 ≥ **1 分钟**(十几秒的片子没有意义)。按 5 秒/镜 ≈ 12-14 镜;即梦引擎可探索 30 秒长镜路线(2 镜即可 1 分钟)
- **质量目标**:画面风格统一、角色长相一致、旁白有情绪起伏、剧情连贯可看
- **效率目标**:全程无人值守,断点可续跑,单镜生成 ≤10 分钟(本地)
- **非目标(暂不做)**:真人级写实画面、多角色对白配音分离、实时生成

## 3. 角色分工

| 角色 | 职责 |
|---|---|
| **用户(制片人)** | 选故事、定风格与画面规格、审剧本、确认角色图/场景图、审成片、排需求优先级 |
| **Claude(技术负责人)** | 流水线开发与维护、质量工具、文档、按制片人意见迭代 |

## 4. 功能需求

### F1 剧本生成
- 输入小说 → 3 个改编方向自评选优 → 8~12 镜分镜梗概 → 逐镜草稿 → 27B 创作级改写
- 每镜产物:英文画面提示词(按分镜公式:运镜+景别+主体+动作+表情+限制)+ 中文旁白(带情绪标签,含对白/表情动作/紧迫感)
- 验收:相邻镜头运镜不重复、情绪标签多样化、角色外貌全程一致、无指令杂质("25字"等)

### F2 资产生成(人工确认环节)
- 剧本完成后自动生成:每个角色的定妆图 + 3 个主要场景设计图
- 制片人确认后,主角图锁定为角色参考(char_ref),后续所有镜头图生视频使用
- 验收:角色图与人物档案描述一致,场景图符合全局风格

### F3 视频生成
- 逐镜生成 720p(1280×544 宽银幕)× 121 帧(≈5秒)@24fps
- 角色一致性:首镜起用确认过的角色参考图做图生视频
- 断点续跑:中断后从断点继续,不重做已完成镜头
- 验收:每镜 121 帧完整、无单帧坏结果、风格与资产图一致

### F4 旁白配音
- edge-tts 神经音色(默认晓晓),旁白情绪标签自动映射语速/音调
- 无标签旁白自动做情绪推断+杂质清理
- 验收:旁白与镜头时长匹配(5秒/镜),情绪与剧情相符

### F5 成片合成
- 逐镜混音(视频+旁白)→ 拼接为单个 mp4,可直接发微信
- 验收:时长≈镜头数×5秒,音画同步,文件 ≤100MB

### F6 全局配置
- settings.json 驱动:模型选择、镜头数、分辨率/帧数/步数、画面定调、音色/语速
- 验收:改配置重跑即可生效,无需改代码

## 5. 非功能需求

- **可靠性**:无人值守跑通整夜不崩;任何单镜失败不影响已完成的镜头(断点)
- **可恢复性**:Ollama/ComfyUI 假死后有标准恢复流程(重启+环境变量)
- **可维护性**:所有关键知识记录在决策树文档,新会话可无缝接管

## 5b. 故事库目录结构(2026-10-17 新增)

每个故事一个独立大目录,所有产物归集其中:

```
E:\ai\stories\<故事名>\
├── story.txt          原始小说
├── directions.json    改编方向
├── script_plan.json   分镜梗概
├── script.json        剧本(含27B改写结果)
├── assets\            角色定妆图/场景设计图(审查门)
├── clips\             分镜片段 mp4
├── audio\             旁白音频
└── final_story.mp4    成片
```

- 切换故事:改 settings.json 的「当前故事」,或 `pipeline.py new <故事名> <源txt>` 新建并切换
- 查看所有故事:`pipeline.py list`
- 工具本体(E:\ai\story2video\)与故事数据分离,故事库可整体备份/迁移

## 6. 约束条件(硬件/模型硬限制)

1. 单镜上限 121 帧 ≈ 5 秒(模型硬限制,"8秒固定时长"为理想值不可达)
2. LLM 与视频模型不能同时占 GPU(排他)
3. 每镜需重启 ComfyUI(ROCm 二镜诅咒的规避)
4. 画幅 2.39:1 的最近合法值 1280×544(宽高须为 32 的倍数)

## 7. 需求优先级

| 级别 | 内容 |
|---|---|
| P0 | F1~F6 现有流程的稳定运行 |
| P1 | 转场优化、字幕、背景音乐、27B 改写上主线 |
| P2 | A14B 画质升级、长篇小说支持、多角色对白分离配音 |
